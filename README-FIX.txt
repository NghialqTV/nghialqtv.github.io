NGHIALQ TV - GOI FIX THU CONG

1. Giữ nguyên thư mục assets/ hiện có của GitHub Pages.
2. Thay index.html bằng file index.html trong gói này.
3. Thay main.js bằng file main.js trong gói này.
4. Giữ style.css gốc nếu đó là CSS đang chạy đúng trên website; file style.css trong gói chỉ là bản dự phòng.
5. Copy thư mục data/ vào repo và đảm bảo có data/mods.json + data/modpacks.json.
6. Copy modpacks.html, modpacks.js, modpacks.css vào thư mục gốc.
7. Nếu tên banner thật khác, sửa các trường image trong data/modpacks.json cho đúng đường dẫn ảnh của bạn.
8. Sửa các link Android/iOS trong data/modpacks.json thành link tải thật. Các link example.com chỉ là placeholder để tránh làm sai link hiện tại của bạn.

THAY ĐỔI ĐÃ CHUẨN BỊ:
- Nhóm Tele -> Bot Tele.
- Bot Tele -> https://t.me/ModSkinNghiaTVBot.
- Giữ icon Telegram lớn cạnh YouTube.
- Có mục Mod Pack trong MOD SKIN với icon assets/icons/modpack.png.
- Bỏ filter Tất Cả / Android / IOS khỏi trang Mod Pack.
- Mỗi pack có Android + iOS cạnh nút Tải Ngay.
- Mod Pack mở trang danh sách version: Ver 1, Ver 2, Ver 3, Ver 4 và Hot Pick.
- Tải Ngay dùng link tải tương ứng.
- Không chạm vào các script quảng cáo hiện tại trong index.html; cơ chế quảng cáo hiện tại được giữ nguyên.
