🔗 Link tải & link ảnh cho từng file

Chọn Tài nguyên, File lẻ hoặc Mod Pack. Ở mỗi file, ô Link ảnh nằm ngay bên dưới ô Link tải. Dán URL ảnh của riêng file đó, ảnh sẽ xem trước ngay cạnh. Trong File lẻ, mỗi file chỉ có một Link ảnh dùng chung và hai Link tải riêng cho Android / iOS.

Lưu ý: Trong Tài nguyên và Mod Pack, mỗi file có ô Link tải và Link ảnh. Ảnh không cần tải lên GitHub. Ở tab File lẻ, dán một Link ảnh dùng chung cho cả hai hệ, sau đó nhập Link tải Android và Link tải iOS độc lập. Link tải cũ được giữ làm dự phòng nếu chưa cập nhật. Do website dùng GitHub Pages tĩnh, sau khi chỉnh hãy bấm Tải JSON đã sửa và thay đúng file trong thư mục data/ trên GitHub để lưu thay đổi cho mọi người.

Đang mở dữ liệu…

Ví dụ cho mỗi file: Link tải: https://linkx.me/... → ngay bên dưới Link ảnh: https://i.imgur.com/anh-file.jpg. Ảnh phải công khai và cho phép nhúng trực tiếp; link trang chia sẻ (ví dụ trang xem Google Drive) có thể không hiển thị. Đường dẫn assets/... cũ vẫn được hỗ trợ. Không cần upload ảnh. Ở File lẻ: một ảnh chung hiển thị ở cả thẻ và cửa sổ chi tiết; chọn Android, iOS hoặc Cả hai rồi nhập đường dẫn tải cho từng hệ. Không cần nhập URL ảnh hai lần.
